# 3D Models Directory

This directory contains 3D models used in the application.

## Energy Drink Can Model

The energy drink can model should be placed in this directory with the filename `energy_drink_can.glb`.

You can download a suitable energy drink can model from Sketchfab:
1. Go to https://sketchfab.com/models/66b14410917743aea577b9c10d76e795
2. Download the model (you may need to create a Sketchfab account)
3. Extract the downloaded ZIP file
4. Rename the .glb file to `energy_drink_can.glb`
5. Place it in this directory
